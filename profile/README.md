# 🍔 PulaFilla

Sistema web de pedidos antecipados para cantinas escolares, desenvolvido com o objetivo de eliminar filas e otimizar o atendimento.

---

## 📌 Sobre o Projeto

O **PulaFilla** é um sistema que permite que alunos realizem pedidos de lanches de forma antecipada, diretamente pelo celular ou computador.

Com isso, o aluno apenas retira o pedido na cantina, evitando filas e melhorando a experiência no ambiente escolar.

---

## 🎯 Objetivos

- Reduzir filas em cantinas escolares  
- Facilitar o processo de compra de alimentos  
- Melhorar a organização dos pedidos  
- Oferecer uma solução simples e eficiente  

---

## 🚀 Funcionalidades

### 👨‍🎓 Aluno
- Cadastro e login  
- Visualização do cardápio  
- Busca de produtos  
- Adicionar itens ao carrinho  
- Realizar pedidos online  
- Acompanhar status do pedido  

---

### 🏪 Cantina (Administrador)
- Cadastro de produtos  
- Organização por categorias  
- Controle de estoque  
- Gerenciamento de pedidos  
- Atualização de status:
  - Pendente  
  - Preparando  
  - Pronto  

---

---

## 🧠 Como o Sistema Funciona

1. O aluno acessa o sistema  
2. Escolhe os produtos desejados  
3. Adiciona ao carrinho  
4. Finaliza o pedido  
5. A cantina recebe o pedido  
6. O pedido é preparado  
7. O aluno retira sem enfrentar fila  

---
